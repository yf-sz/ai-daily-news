## 📄 最新论文速览

**1. [MuSEAgent: A Multimodal Reasoning Agent with Stateful Experiences](https://arxiv.org/abs/2603.27813)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.CL` &nbsp;|&nbsp; 🗓 2026-03

  > MuSEAgent 提出了一种带有持久化状态经验记忆的多模态推理智能体架构。与现有"无状态"推理框架不同，MuSEAgent 引入可跨任务积累的视觉—文本联合经验存储模块，并在推理时动态检索相关历史经验。在多模态问答和视觉推理基准上，MuSEAgent 比无状态基线提升 12–18%，在多轮对话场景中展现出显著的上下文连贯性，为面向长期任务的 Agentic AI 系统提供了新范式参考。

**2. [EpiBench: Benchmarking Multi-turn Research Workflows for Multimodal Agents](https://arxiv.org/abs/2604.05557)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.CL` &nbsp;|&nbsp; 🗓 2026-04

  > EpiBench 构建了专门面向流行病学研究场景的多轮多模态 Agent 评测框架。基准覆盖数据收集、假设验证、文献检索和报告撰写等完整研究工作流，要求 Agent 在多轮交互中持续整合新信息并动态更新结论。测评发现，当前最先进的 Agent 系统在需要跨轮次整合证据的复杂推理任务上仍存在明显短板，最优模型完整工作流完成率不足 60%，为科学研究型 AI Agent 的系统化评测提供了高质量基准。

**3. [Agentic Reasoning for Large Language Models](https://arxiv.org/abs/2601.12538)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.LG` &nbsp;|&nbsp; 🗓 2026-01

  > 本综述系统梳理了 LLM 从"静态推理"向"动态 Agentic 推理"演进的研究脉络，涵盖工具调用、多步规划、自我反思与外部记忆四大维度。论文总结了当前 Agentic LLM 的主要挑战：长程任务中的错误累积、工具选择的泛化困难以及安全边界的模糊性，并提出了基于"能力—限制—安全"三维度的统一评估框架，已成为 2026 年 Agent 研究领域引用最广的参考综述之一。

**4. [DART: Leveraging Multi-Agent Disagreement for Tool Recruitment in Multimodal Reasoning](https://arxiv.org/abs/2512.07132)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.CV` &nbsp;|&nbsp; 🗓 2025-12

  > DART 提出利用多智能体"不一致性信号"动态决定何时引入外部工具辅助推理。当多个 Agent 对同一问题给出分歧答案时，系统自动触发工具招募（如调用计算器、检索数据库或执行代码），再协调收敛至一致答案。在多模态数学推理和视觉问答任务上，DART 较单 Agent 基线准确率提升 9.3%，工具调用次数减少 31%，实现了精度与效率的双重优化。

**5. [Real-Time Reasoning Agents in Evolving Environments](https://arxiv.org/abs/2511.04898)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.LG` &nbsp;|&nbsp; 🗓 2025-11

  > 本文研究 LLM 智能体在动态变化环境中的实时推理与决策能力。研究者构建了环境状态随时间演化的评测场景，模拟真实工业监控、金融交易和自主机器人等应用。实验表明，当环境变化速率超过 Agent 的上下文更新频率时，推理准确率急剧下降（降幅达 40%+）；研究提出了基于异步感知—推理解耦架构的改进方案，为实时 Agent 系统设计提供了理论指导。
