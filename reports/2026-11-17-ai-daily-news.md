**1. [What LLM Agents See and What Users Say](https://arxiv.org/abs/2611.17639)**
  👤 Yifei Wang, Stanford NLP Group &nbsp;|&nbsp; 📂 `cs.AI · cs.CL` &nbsp;|&nbsp; 🗓 2026-11-13
  [PDF](https://arxiv.org/abs/2611.17639)

  > 借助语言学中的"预设"（presupposition）理论，系统研究 LLM Agent 在工具输出与用户指令相互矛盾时的行为准则。提出"预设感知代理"框架，使代理能区分用户言外之意与工具返回的事实，在矛盾场景下正确率提升 31%。对金融、法律等高可靠性需求场景有直接工程指导意义。

**2. [When Should LLM Agents Forget? Memory Lifecycle Management for Long-Running Agents](https://arxiv.org/abs/2611.17338)**
  👤 Peilin Zhao, MIT CSAIL, Princeton NLP &nbsp;|&nbsp; 📂 `cs.CL · cs.AI` &nbsp;|&nbsp; 🗓 2026-11-16
  [PDF](https://arxiv.org/abs/2611.17338)

  > 提出首个面向长期运行 Agent 的"记忆生命周期管理"框架，定义记忆的写入、压缩、遗忘三个阶段，并给出在上下文窗口有限条件下的最优遗忘策略。在 100 轮以上对话任务中，任务成功率提升 28%，同时幻觉率降低 42%。对 Meta Muse Ember 等百万 Token 上下文模型的部署具有直接参考价值。

**3. [More Agents, More Samples, or More Thinking? Scaling Laws for Agentic AI](https://arxiv.org/abs/2611.17610)**
  👤 Zhuang Liu, Tri Dao, Together AI Research &nbsp;|&nbsp; 📂 `cs.LG · cs.AI` &nbsp;|&nbsp; 🗓 2026-11-16
  [PDF](https://arxiv.org/abs/2611.17610)

  > 通过系统实验对比三种 AI Agent 扩展路径：增加并行代理数量、增加采样次数（best-of-N）、增加推理计算（Chain-of-Thought）。发现在等算力预算下，"更多思考"（扩展推理计算）在开放任务上最有效，而"更多代理"在并行可分解任务上最优。为大规模 Agent 系统的算力分配提供了量化指导。

**4. [Towards Identity-Preserving LLM Agents under Model Transition](https://arxiv.org/abs/2611.10628)**
  👤 Ruoyu Sun, Xiang Li, Tsinghua NLP Lab &nbsp;|&nbsp; 📂 `cs.CL · cs.AI` &nbsp;|&nbsp; 🗓 2026-11-07
  [PDF](https://arxiv.org/abs/2611.10628)

  > 研究当 LLM Agent 底层模型发生迭代升级（如从 GPT-5 切换至 GPT-5.5）时，如何保留 Agent 的"身份一致性"——包括记忆、个性和行为风格。提出轻量级适配层，使跨版本身份保真度（Identity Fidelity Score）达到 91%，远超无适配时的 63%，为 Agent 产品化部署中的模型升级问题提供实用解法。

**5. [Agentic Environment Engineering: A Survey of Environment Modeling, Synthesis and Evaluation](https://arxiv.org/pdf/2606.12191)**
  👤 Ziwei Ji, Nanyang Technological University, CMU LTI &nbsp;|&nbsp; 📂 `cs.AI · cs.SE` &nbsp;|&nbsp; 🗓 2026-11-15
