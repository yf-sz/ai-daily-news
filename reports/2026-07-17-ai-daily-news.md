## 📄 最新论文速览

**1. [World Action Models: A Survey](https://arxiv.org/abs/2606.20781)**
  👤 arXiv 研究团队 &nbsp;|&nbsp; 📂 `cs.AI · cs.LG` &nbsp;|&nbsp; 🗓 2026-06-30
  [PDF](https://arxiv.org/pdf/2606.20781)

  > 系统梳理"世界行动模型"（World Action Models, WAMs）这一新兴研究方向——将传统世界模型与动作预测能力整合，使 Agent 能够在内化的环境表征中进行行动规划与推演。论文覆盖 WAMs 的体系结构分类、训练范式（对比式预测、掩码自回归、扩散解码）以及在机器人控制、游戏智能体、具身导航中的应用现状。作者指出当前核心挑战：现有 Agent 普遍未能将世界模型作为前瞻推理工具，而是退化为被动的状态编码器，论文给出了改进路线图。

**2. [Self-Evolving World Models for LLM Agent Planning](https://arxiv.org/abs/2606.30639)**
  👤 多机构合作研究团队 &nbsp;|&nbsp; 📂 `cs.AI · cs.LG · cs.CL` &nbsp;|&nbsp; 🗓 2026-06-28
  [PDF](https://arxiv.org/pdf/2606.30639)

  > 提出"自进化世界模型"框架：LLM Agent 在规划过程中持续更新其内部环境模型，而非依赖静态快照。核心机制是一个双循环结构——内循环在单次规划中修正局部预测误差，外循环跨任务累积经验并蒸馏到模型权重。在多个长程任务基准（WebArena、MiniWob++）上，自进化世界模型相比固定世界模型将任务完成率提升 18—24%，同时减少无效行动步骤约 30%，为构建更自主、更稳健的 Agent 提供了有力工具。

**3. [Object-Centric Environment Modeling for Agentic Tasks](https://arxiv.org/abs/2607.02846)**
  👤 arXiv 独立研究团队 &nbsp;|&nbsp; 📂 `cs.AI · cs.CV · cs.RO` &nbsp;|&nbsp; 🗓 2026-07-03
  [PDF](https://arxiv.org/pdf/2607.02846)

  > 针对 Agent 在复杂视觉环境中的建模难题，提出以"对象为中心"的环境表征方法：将原始像素流分解为结构化对象实体图，每个实体附带属性、关系与时序状态，由此构建稀疏且高解释性的场景图。相较于端到端视觉 Transformer 直接建模环境，对象中心表征在样本效率上提升约 3 倍，并在机械臂抓取与导航任务上展示出更强的泛化迁移能力，支持 zero-shot 跨场景部署。

**4. [World-Model Collapse as a Phase Transition](https://arxiv.org/abs/2606.31399)**
  👤 arXiv 理论研究团队 &nbsp;|&nbsp; 📂 `cs.LG · stat.ML` &nbsp;|&nbsp; 🗓 2026-07-01
  [PDF](https://arxiv.org/pdf/2606.31399)

  > 从统计物理角度将"世界模型崩塌"（World-Model Collapse）现象类比为相变：当 Agent 的自生成数据混入预训练语料超过临界比例时，模型表征急剧退化，呈现类似铁磁体居里温度附近的突变特征。研究推导出崩塌阈值的理论公式，量化了合成数据污染对世界模型质量的临界影响，并提出基于能量函数的早期预警检测方法，为构建数据飞轮系统的 AI 公司提供了重要安全边界参考。

**5. [Qwen-AgentWorld: Language World Models for General Agents](https://arxiv.org/abs/2606.24597)**
  👤 Qwen 团队（阿里巴巴达摩院） &nbsp;|&nbsp; 📂 `cs.AI · cs.CL` &nbsp;|&nbsp; 🗓 2026-06-25
  [PDF](https://arxiv.org/pdf/2606.24597)

  > 阿里巴巴 Qwen 团队提出 AgentWorld——将语言模型直接用作通用 Agent 的世界模拟器：给定动作序列，模型预测环境状态变化及奖励信号，形成内部"语言仿真器"。在 ALFWorld、BabyAI 和 ScienceWorld 三个标准 Agent 基准上，以 Qwen 系列语言模型驱动的 AgentWorld 相比传统神经世界模型在规划准确率上提升 12—21%，且无需额外环境渲染即可扩展到新任务，展现出语言先验在构建泛化世界模型方面的独特潜力。
