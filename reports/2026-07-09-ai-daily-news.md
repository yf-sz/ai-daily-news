**1. [Your Agent's Memories Are Not Its Own: Forged Reasoning Attacks on LLM Agent Memory and Defenses](https://arxiv.org/abs/2607.05029)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.AI · cs.CR` &nbsp;|&nbsp; 🗓 2026-07-06
  [PDF](https://arxiv.org/pdf/2607.05029)

  > 本文提出 FARMA（Forged Amplifying Rationale Memory Attack），一种新型 LLM Agent 安全攻击方式。与传统知识投毒不同，FARMA 针对 Agent 的推理记忆（reasoning memory）而非事实记忆发动攻击——通过将带有恶意偏见的推理链注入 Agent 的情节记忆（episodic memory），使其在未来类似场景中系统性地复现错误决策。实验表明，在 ReAct、Reflexion 等主流 Agent 框架上，FARMA 攻击成功率超过 80%，且现有防御机制难以有效应对。该研究揭示了 LLM Agent 记忆系统的根本性安全盲点。

**2. [Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training](https://arxiv.org/abs/2607.01232)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.LG · cs.AI` &nbsp;|&nbsp; 🗓 2026-07-01
  [PDF](https://arxiv.org/pdf/2607.01232)

  > 本文对强化学习微调（RLHF/RLVR）在 Transformer 中的参数分布进行了精细化分析，发现约 80% 的 RL 行为改变集中在最后几层的注意力头和 FFN，尤其是最终的单层 Transformer Block。基于这一发现，作者提出"单层 RL 微调"方案：冻结所有其他层，仅对最后一个 Transformer 层做全参数更新，在多个对齐基准（HH-RLHF、TruthfulQA、AlpacaEval）上取得与全参数 RL 相当的性能，同时计算成本降低 90%，为大模型高效对齐提供了新视角。

**3. [Will Scaling Improve Social Simulation with LLMs?](https://arxiv.org/abs/2607.02464)**
  👤 Caleb Ziems 等 &nbsp;|&nbsp; 📂 `cs.CL · cs.AI` &nbsp;|&nbsp; 🗓 2026-07-02
  [PDF](https://arxiv.org/pdf/2607.02464)

  > 本文系统评估了扩展定律（scaling laws）是否同样适用于基于 LLM 的社会模拟任务。作者在覆盖 12 种社会科学情境（选举行为、经济博弈、群体动力学等）的基准上，对 7B 至 100B+ 参数规模的模型进行对比测试。结论出人意料：社会模拟保真度并不随模型规模单调增长——部分较小模型在特定社会互动场景下表现超越更大模型，反映出"涌现但不均匀"的社会推理能力。研究建议针对社会模拟设计专项微调数据，而非简单依赖规模扩展。

**4. [Prototype Language Models: Interpretable Sequence Modeling with PRISM](https://arxiv.org/abs/2607.00510)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.LG · cs.CL` &nbsp;|&nbsp; 🗓 2026-07-01
  [PDF](https://arxiv.org/pdf/2607.00510)

  > 本文提出 PRISM（Prototypes for Interpretable Sequence Modeling），一种将原型网络（Prototype Networks）引入语言模型解码阶段的可解释架构。PRISM 在生成每个 token 时，显式将当前表示映射到可解读的语义原型集合，使人类可以追踪模型"为何选择这个词"背后的最近原型推理路径。在文本分类、生物医学命名实体识别和代码补全任务中，PRISM 在可解释性指标上大幅优于黑盒基线，准确率损失控制在 2% 以内，为合规性要求严格的场景提供了可落地的替代方案。

**5. [AgenticDataBench: Evaluating LLM Data Agents Across 15 Domains and B2B Fintech Use Cases](https://letsdatascience.com/news/researchers-release-agenticdatabench-for-llm-data-agents-f3a2fd61)**
