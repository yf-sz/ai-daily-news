## 📄 最新论文速览

**1. [MLA-Trust: Benchmarking Trustworthiness of Multimodal LLM Agents in GUI Environments](https://arxiv.org/abs/2506.01616)**
  👤 Xiao Yang, Jiawei Chen, Jun Luo 等 &nbsp;|&nbsp; 📂 `cs.AI · cs.CL` &nbsp;|&nbsp; 🗓 2026-06-02
  [PDF](https://arxiv.org/pdf/2506.01616) · [Code](https://github.com/thu-ml/MLA-Trust)

  > 首个评估多模态 LLM Agent（MLA）可信度的综合框架，覆盖真实性、可控性、安全性与隐私四个维度，提出 34 项交互任务基准。针对 GUI 环境中 Agent 可直接修改数字状态、引发不可逆后果的独特风险，填补了现有评测的空白。

**2. [ShardMemo: Masked MoE Routing for Sharded Agentic LLM Memory](https://arxiv.org/abs/2601.21545)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.LG · cs.AI` &nbsp;|&nbsp; 🗓 2026-01
  [PDF](https://arxiv.org/pdf/2601.21545)

  > 提出三层预算式 Agent 记忆服务（工作状态层 / 分片证据层 / 技能库层），通过掩码混合专家（MoE）路由仅探测符合条件的分片，在 HotpotQA 长上下文场景（56K–448K token）实现最高 63.41 F1，同时显著降低检索延迟。

**3. [MemCtrl: Using MLLMs as Active Memory Controllers on Embodied Agents](https://arxiv.org/abs/2601.20831)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.AI · cs.RO` &nbsp;|&nbsp; 🗓 2026-01
  [PDF](https://arxiv.org/abs/2601.20831)

  > 为具身 Agent 设计可训练记忆门控机制，MLLM 在线决策哪些观测应保留、更新或丢弃，从而在严格内存与算力约束下实现高效压缩与检索。在 EmbodiedBench 多项子集上平均提升约 16%，特定指令子集提升超 20%。

**4. [GUIGuard: Toward a General Framework for Privacy-Preserving GUI Agents](https://arxiv.org/abs/2601.18842)**
  👤 多位作者 &nbsp;|&nbsp; 📂 `cs.AI · cs.CR` &nbsp;|&nbsp; 🗓 2026-01
  [PDF](https://arxiv.org/pdf/2601.18842)

  > 针对 GUI Agent 在执行任务时暴露敏感个人信息的风险，提出通用隐私保护框架 GUIGuard，通过细粒度权限控制和上下文感知数据脱敏，在保留 Agent 功能的同时防止隐私泄露。
