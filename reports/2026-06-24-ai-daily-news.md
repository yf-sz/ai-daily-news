## 📄 最新论文速览

**1. [BAGEN: Are LLM Agents Budget-Aware?](https://arxiv.org/abs/2606.00198)**
  👤 Yuxiang Lin, Zihan Wang et al. &nbsp;|&nbsp; 📂 `cs.AI` · `cs.CL` &nbsp;|&nbsp; 🗓 2026-06-01
  [PDF](https://arxiv.org/html/2606.00198v1)

  > 来自 Northwestern、Michigan、Cornell、Stanford 等六所高校的联合研究揭示：前沿 LLM Agent 的任务性能与预算意识之间相关系数仅为 r=0.35，Agent 强不等于会"量力而行"。实验跨越 5 个前沿模型和 4 种 Agent 环境，发现 Agent 常在已注定失败的任务上继续消耗 token 直至耗尽。关键发现：对失败轨迹实施早停可节省 28–64% token。论文呼吁 AI 系统设计者将预算感知纳入 Agent 基础能力评估框架。

**2. [Phoenix: Safe GitHub Issue Resolution via Multi-Agent LLMs](https://arxiv.org/abs/2606.20243)**
  👤 Kipngeno Koech, Muhammad Adam et al. &nbsp;|&nbsp; 📂 `cs.SE` · `cs.AI` &nbsp;|&nbsp; 🗓 2026-06-18
  [PDF](https://arxiv.org/html/2606.20243)

  > Phoenix 提出六 Agent 协作流水线（Planner → Reproducer → Coder → Tester → Failure Analyst → PR Agent），通过 GitHub Webhook 状态机协调全程，内置 7 层安全控制与基线测试比对机制，确保每次 PR 前自动验证无回归。在 SWE-bench Lite 24 个实例上 oracle 解决率达 75%，在 14 个真实仓库 42 个 issue 的生产试点中保持 100% 正确性。为 agentic 代码修复的安全可控部署树立新标杆。

**3. [SpecEyes: Accelerating Agentic Multimodal LLMs via Speculative Perception and Planning](https://arxiv.org/abs/2603.23483)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.CV` · `cs.AI` &nbsp;|&nbsp; 🗓 2026-03-29
  [PDF](https://arxiv.org/pdf/2603.23483)

  > SpecEyes 针对多模态 LLM Agent 的视觉感知瓶颈，提出"推测感知 + 规划"双重加速框架：在感知层引入草稿模型快速预提取视觉 token 候选，在规划层采用轻量推测解码提前生成行动序列，由主模型异步验证。在 GUI 基准任务上实现 2.8×–4.1× 的端到端加速，同时保持与完整推理相当的任务完成率，为大规模部署 Agentic 多模态 LLM 提供可行路径。

**4. [Auditing Multi-Agent LLM Reasoning Trees Outperforms Majority Vote and LLM-as-Judge](https://arxiv.org/abs/2602.09341)**
  👤 Multiple Authors &nbsp;|&nbsp; 📂 `cs.AI` · `cs.CL` &nbsp;|&nbsp; 🗓 2026-02-13
  [PDF](https://arxiv.org/pdf/2602.09341)

  > 针对主流 LLM 评估范式的深度审视：通过系统性审计多 Agent 推理树（MART）可同时超越多数投票（Majority Vote）和 LLM-as-Judge 两类方法。研究表明，显式建模 Agent 推理路径的一致性与分歧模式，比单纯聚合输出或单一裁判评估更能捕捉推理质量信号，对 RLHF 数据标注与模型评测流程有直接指导意义。

**5. [RACL: Reasoning-Agent Control Layers for Continuous Metaheuristic Learning](https://arxiv.org/list/cs.AI/current)**
  👤 Zhibang Yang, Xinke Jiang et al. &nbsp;|&nbsp; 📂 `cs.AI` · `cs.NE` &nbsp;|&nbsp; 🗓 2026-06
  [PDF](https://arxiv.org/list/cs.AI/current)

  > RACL 将推理 Agent 控制层嵌入元启发式优化循环，实现 LLM 推理能力与经典启发式搜索算法的深度融合。框架通过动态调整搜索策略参数、识别停滞信号并切换邻域结构，在旅行商、车辆路径、调度等组合优化基准上相较纯 LLM 与纯启发式方案均取得显著提升，为"AI+运筹"融合提供新型控制架构。
