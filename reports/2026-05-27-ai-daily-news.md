**1. [ConvexTok: Near-Optimal Tokenization via Integer Program Relaxation](https://arxiv.org/list/cs.CL/current)**
  👤 ETH Zurich & Kensho Technologies 研究团队 &nbsp;|&nbsp; 📂 `cs.CL` &nbsp;|&nbsp; 🗓 2026-05-26

  > ETH Zurich 和 Kensho Technologies 联合提出 ConvexTok——一种将分词问题建模为整数规划（IP）并通过线性规划（LP）松弛求解的新型分词算法。该方法在理论上可证明达到全局最优解的 1% 以内压缩率，相较现有 BPE 等启发式方法具备更强的理论保证，有望改善大语言模型的输入表示效率。

**2. [From Backward Spreading to Forward Replay: Revisiting Target Construction in LLM Parameter Editing](https://arxiv.org/list/cs.AI/current)**
  👤 Wei Liu, Hongkai Liu, Zhiying Deng, Yee Whye Teh, Wee Sun Lee &nbsp;|&nbsp; 📂 `cs.AI · cs.LG` &nbsp;|&nbsp; 🗓 2026-05-26

**3. [Agent Capsules: Quality-Gated Granularity Control for Multi-Agent LLM Pipelines](https://arxiv.org/list/cs.MA/current)**
  👤 Aninda Ray &nbsp;|&nbsp; 📂 `cs.MA · cs.CL` &nbsp;|&nbsp; 🗓 2026-05-26

  > 本文提出"代理胶囊"（Agent Capsules）框架，针对多智能体 LLM 流水线中信息粒度控制问题引入质量门控机制。通过动态调整智能体之间传递内容的详细程度，该方法在保持整体输出质量的同时显著降低了 token 消耗与延迟，适用于复杂多跳推理与自动化工作流场景。

**4. [Escaping Mode Collapse in LLM Generation via Geometric Regulation](https://arxiv.org/list/cs.CL/current)**
  👤 Xin Du, Kumiko Tanaka-Ishii &nbsp;|&nbsp; 📂 `cs.CL` &nbsp;|&nbsp; 🗓 2026-05-26

  > LLM 解码时常出现"模式崩溃"（mode collapse）——输出词汇多样性下降、重复内容增多。本文从几何角度分析了该现象的成因，提出基于概率单纯形几何约束的正则化解码方法，在开放域生成任务中有效提升了输出多样性，同时保持语义连贯性与流畅度。

**5. [Understanding Emergent Misalignment via Feature Superposition Geometry](https://arxiv.org/list/cs.AI/current)**
  👤 ACL 2026 入选论文 &nbsp;|&nbsp; 📂 `cs.AI · cs.LG` &nbsp;|&nbsp; 🗓 2026-05-25

  > 该研究（已被 ACL 2026 录用）从特征叠加几何视角分析 LLM 中"涌现式对齐失效"（emergent misalignment）现象的形成机制。通过对模型内部表征的几何分析，揭示了多种能力在有限维空间中共存时引发价值对齐偏差的内在规律，为构建更鲁棒的对齐方法提供了理论依据。
